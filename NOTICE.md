# Créditos

Este projeto é um fork de [pomber/git-history](https://github.com/pomber/git-history),
criado e mantido por **Rodrigo Pombo ([@pomber](https://github.com/pomber))**,
distribuído sob a licença MIT (veja o arquivo `license`).

Todo o conceito, a arquitetura e a maior parte do código pertencem ao autor original.

## Alterações neste fork (Git File History CDM)

- Exibição dos números das linhas, com coluna fixa durante o scroll horizontal.
- Linhas exibidas por inteiro, sem corte, com scroll horizontal.
- Cores de sintaxe baseadas no tema Dark+ do VS Code (`src/darkPlus.js`).
- Extensão do VS Code renomeada para "Git File History CDM".
